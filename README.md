# 💻 Laptop Price Prediction

This project predicts the price of a laptop based on its hardware and software configuration using **Machine Learning**.

## 🔹 Project Overview

* Built a regression model to predict laptop prices.
* Performed **data preprocessing, feature engineering, and model training** in Jupyter Notebook.
* Created an interactive **web application with Streamlit** where users can select laptop specifications (brand, processor, RAM, storage, OS, etc.) and instantly get the predicted price.

## 🔹 Features

* 📊 Data analysis and preprocessing on real-world laptop dataset.
* 🤖 Machine learning model trained with scikit-learn.
* 🌐 Streamlit-based user-friendly web app for live predictions.
* 📦 Pickle used to save the trained model.

## 🔹 Tech Stack

* **Python** (pandas, numpy, scikit-learn)
* **Jupyter Notebook** for model building
* **Streamlit** for web app development
* **Pickle** for model serialization
